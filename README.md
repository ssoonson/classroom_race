# 우리 반 콩콩 달리기 — 정적 3D 랜덤 경주 웹앱 (v4 에셋 + 모듈 구조)

**바로 실행:** https://ssoonson.github.io/classroom_race/ (GitHub Pages)

교사 컴퓨터 한 대에서 실행하는 브라우저 기반 3D 자동 달리기 게임입니다. **게임 서버/DB가 필요 없습니다.**

## 기능
- 설정 5개 탭: 학생 명단, 참가선수, 모둠 나누기, 순서 기록, 화면·소리
- 반 이름, 최대 40명, 번호 모드, 브라우저 자동 저장, 백업 JSON 불러오기/내보내기
- 라운드 블록 레이서 또는 젤리 헬멧 레이서 (참가 순번마다 몸 색·헬멧 장식·모자가 다름)
- **테마 투어**(다섯 배경이 이어지는 곡선 코스, 기본) / 무지개 운동장(곡선) / 우주 스피드웨이 / 바다 산책로
- 1배 60초, 1.5배 40초, 2배 30초
- 경기 전 Web Crypto 기반 편향 없는 Fisher–Yates 셔플로 전체 순위 확정
- 낮은 장애물은 점프, 회전목마·사탕 공처럼 높은 것은 옆으로 비켜 감. 추월 연출. 마지막 참가자는 정확히 경기 시간에 완주
- 카메라 자동 전환 / 전체 보기 / 특정 학생 추적, 결과 CSV 내보내기, 전체 화면

## 실행
JavaScript 모듈을 쓰므로 `index.html`을 더블클릭(file://)하지 말고 웹 서버로 여세요.

```bash
cd classroom-race
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`으로 접속합니다.

## 배포
**`index.html`, `css/`, `js/` 폴더를 통째로** 올려야 합니다. 폴더 구조가 그대로 유지돼야 합니다.
Three.js가 `js/lib/`에 들어 있어 인터넷(CDN) 없이도 동작합니다.
- **Netlify Drop**: `classroom-race` 폴더를 드래그 앤 드롭
- **GitHub Pages / Vercel**: 저장소 루트에 그대로 올리고 정적 사이트로 배포
- **닷홈 등 FTP**: `/html` 아래에 `index.html`, `css/`, `js/`를 같은 구조로 업로드

### 자주 하는 수정
| 하고 싶은 것 | 고칠 파일 |
|---|---|
| 캐릭터 모양·색·모자 바꾸기 | `js/game/characters/racer.js` |
| 새 캐릭터 추가 | `characters/`에 파일 추가 → `characters/index.js`, `core/config.js`에 한 줄씩 |
| 테마 투어 한 구간만 바꾸기 | `js/game/tracks/tour/`의 해당 구간 파일 |
| 트랙 장식 바꾸기 | `js/game/tracks/rainbow.js` / `space.js` / `ocean.js` |
| 새 트랙 추가 | `tracks/`에 파일 추가 → `tracks/index.js`, `core/config.js`에 한 줄씩 |
| 장애물 위치 옮기기 | 각 트랙 파일의 `obstacles` 목록 (점프·비키기가 자동으로 따라감) |
| 첫 화면 문구·버튼 | `js/ui/start-screen.js`, `css/start-screen.css` |
| 설정 탭 내용 | `js/ui/settings/tab-*.js` |
| 경기 시간·속도 단계 | `js/core/config.js` |
| 긴장감 세기(역전·스퍼트) | `js/game/race.js` 위쪽의 `STORY`, `WAVE`, `SPURT_*` |
| 카메라 샷 순서·길이 | `js/game/camera.js` 위쪽의 `MID_RACE_SHOTS`, `SHOT_SECONDS` |
| 알림 문구 | `js/ui/announcer.js` |
| 효과음 / 기본 음악 | `js/core/audio.js` / `js/core/bgm.js` |

모듈끼리는 서로 직접 부르지 않고 `core/events.js`의 이벤트(`state:changed`, `race:phase` 등)로 소식을 주고받습니다. 그래서 한 화면 파일을 고쳐도 다른 화면이 깨지지 않습니다.

## 긴장감 업데이트 (최신)
1분 동안 눈을 떼지 못하도록 경기 연출을 바꿨습니다. **순위는 여전히 출발 전에 공정하게 확정**되고, 아래 연출은 보여 주는 방식만 바꿉니다.
- **3·2·1·GO!** 카운트다운 (경기 시간 60초와 별도로 3초)
- **선두 다툼 대본**: 경기 중반에 여러 선수(가끔 하위권 다크호스)가 차례로 스퍼트해 선두를 빼앗습니다. 절반은 우승자가 뒤처졌다가 막판에 역전합니다. 인원과 관계없이 경기마다 선두 교체가 4번 이상 일어나는 것을 시뮬레이션으로 확인했습니다.
- **카메라 감독**: 3~5초마다 추격·정면·옆·접전·전체·결승선 샷으로 컷 전환. 가까운 샷일수록 시야를 넓혀 속도감을 줍니다.
- **알림**: 선두 교체, 구간 진입, 마지막 10초, 1~3위 골인을 화면 가운데 크게 표시
- **마지막 10초**: 타이머가 빨갛게 깜빡이고, 경기장 테두리가 빛나고, 속도선과 초읽기 소리, 빨라지는 음악
- **진행 바**: 화면 위에 모든 선수를 색 점으로 표시(선두 👑). 오른쪽 순위표에는 ▲▼ 순위 변동
- **골인**: 1~3위가 들어올 때 꽃가루와 팡파르
- **배경음악**: 기본 음악 내장(마지막 10초에 빨라짐). 선생님 음악 파일도 쓸 수 있습니다(아래 '배경음악').
- '카메라 움직임 줄이기'를 켜면 컷 전환·흔들림·깜빡임 없이 전체 보기로만 보여 줍니다.

## 배경음악
설정 → **배경음악** 탭에서 고릅니다.
- **기본 음악 (내장)**: 파일 없이 바로 나오는 신나는 음악. 마지막 10초에 빨라집니다.
- **내 음악 파일**:
  - 이 컴퓨터에서만: ‘음악 파일 고르기’로 mp3 등을 고르면 그 브라우저에 보관됩니다.
  - 모든 컴퓨터에서: 저장소의 `audio` 폴더에 `bgm.mp3`로 올립니다(`audio/README.md` 참고).
  - 마지막 10초에는 재생 속도를 10% 올립니다(음 높이는 그대로).
- **끄기**. 음량 조절과 미리 듣기도 있습니다. 효과음은 ‘화면·소리’ 탭에서 따로 켜고 끕니다.
- 공개 사이트에 올리는 음악은 무료 이용이 허락된 곡만 쓰세요.

## v4 에셋 반영
에셋 v4(레이서 캐릭터, 곡선 무지개 운동장, 테마 투어, Three.js 내장)를 모듈 구조에 맞게 옮겼습니다.
- **테마 투어**: 온실 출발역 → 무지개 정원 → 별빛 고가교 → 산호 해변 → 노을 축제장. 경기 중 상단에 지금 구간과 순서(예: `🌈 무지개 정원 · 2/5`)가 표시되고, 하늘·안개 색이 구간에 맞춰 바뀝니다. 카메라에서 먼 구간은 숨겨서 가볍게 그립니다.
- **레이서 캐릭터**: 달리는 방향을 바라보고, 곡선을 따라 몸을 돌립니다. 24가지 몸 색, 5가지 장식 색, 3가지 모자.
- **점프·회피**: 장애물마다 넘을지 비킬지를 정해 두었습니다. 40명이 끝까지 달리는 동안 장애물을 뚫고 지나가는 경우가 없음을 자동 검사로 확인했습니다.
- **성능**: 새 캐릭터·배경도 도형 합치기를 적용하고, 작은 구는 면이 적은 구로 자동 교체합니다(레이서 1명 약 6천 → 3천 삼각형).
- 이전에 저장한 트랙 설정(무지개 운동장 등)은 그대로 유지됩니다. 테마 투어를 쓰려면 설정 → 화면·소리 → 트랙 선택에서 고르세요. 처음 쓰는 브라우저는 테마 투어로 시작합니다.

## v3에서 고친 점
- **점프 위치**: 장애물과 점프가 같은 좌표표(`layout.js`)를 쓰도록 바꿔, 캐릭터가 장애물을 뚫지 않고 넘습니다. 장애물 종류마다 점프 높이가 다릅니다.
- **팔다리 관절**: 팔은 어깨, 다리는 엉덩이를 축으로 흔들립니다. 블록 피규어의 신발이 다리와 함께 움직입니다.
- **젤리빈 동작**: 공 모양 팔·발을 관절에서 떨어뜨려 매달아 앞뒤로 흔들리는 게 보입니다. 몸통이 통통 튀며 찌그러집니다.
- **걸음 속도**: 걸음이 시간이 아니라 달린 거리에 맞춰집니다. 2배속이면 발도 빨라지고, 결승 후에는 멈춰 섭니다.
- **뒤 줄 선수 순간이동 제거**: 9번째 선수부터 뒤 줄에서 출발해 자연스럽게 따라옵니다.
- **경기 중 설정 변경**: 경기 시작 순간의 설정을 고정합니다. 경기 중에 속도·트랙·캐릭터·명단을 바꾸거나 백업을 불러와도 진행 중인 경기는 그대로이고 다음 경기부터 적용됩니다.
- **동명이인**: 지우지 않고 `김민준(3번)`처럼 번호를 붙여 구분합니다. `3반장`처럼 숫자로 시작하는 이름도 지키도록 번호 떼기 규칙을 고쳤습니다.
- **백업 검증**: 불러온 파일의 모든 값을 검사합니다(잘못된 속도·트랙, 깨진 기록, HTML 삽입 차단). CSV는 엑셀 수식 실행을 막습니다.
- **탭 전환**: 화면을 내리면 자동 일시정지합니다(돌아왔을 때 경기가 한순간에 끝나던 문제).
- **초기 접속 화면**: 참가 인원·트랙·속도·캐릭터를 보여 주는 READY 카드와 시작/설정 버튼. 처음 방문일 때만 설정 창이 자동으로 열립니다.
- **모둠 나누기**: 참가자보다 모둠 수가 많을 때 빈 모둠이 생기지 않습니다.
- **CDN 차단 안내**: Three.js를 못 불러오면 빈 화면 대신 원인을 알려 줍니다.

## 성능 최적화 (v3.1)
40명·트랙별로 측정한 결과입니다(같은 화질 '높음' 기준).

| 항목 | 이전 | 이후 |
|---|---|---|
| 한 프레임 그리기 호출 | 668~1,241회 | 266~347회 |
| 삼각형 수 | 6만~21만 | 3만~9만 |

- **도형 합치기**: 움직이지 않는 배경(나무·아치·도로 등 수백 개)은 한 덩어리로 합치고, 캐릭터는 몸통 1개와 팔다리 4개로 합칩니다(`parts.js`의 `bakeInto`). 색은 정점 색상으로 보존되므로 만드는 코드는 예전처럼 "도형 붙이기"로 읽고 고치면 됩니다.
- **면 수 줄이기**: 눈 같은 작은 구, 멀리 있는 나무 열매·조개·구름은 면을 적게 씁니다.
- **그림자**: 장식은 그림자를 드리우지 않고, 선수와 장애물만 드리웁니다.
- **그래픽 품질 자동 조절**: 설정 > 화면·소리 > 그래픽 품질. 기본값 '자동'은 '높음'으로 시작합니다. 경기 중에 40fps가 안 나오면 '보통'(해상도 1배), 그래도 느리면 '낮음'(그림자 끔, 해상도 0.75배)으로 내리고, 알아낸 단계를 이 브라우저에 기억합니다.
- **대기 중 30fps**: 경기 중이 아닐 때는 30fps로만 그려 노트북 발열·배터리를 아낍니다.
- **진단**: 주소 끝에 `?debug`를 붙이면(예: `http://localhost:8080/?debug`) 왼쪽 아래에 fps·그리기 호출·삼각형 수가 보입니다.

## 기술 및 한계
- Three.js 0.170.0(MIT)을 `js/lib/`에 포함했습니다. 공식 배포 파일과 같은 파일입니다.
- 캐릭터·배경은 모두 기본 도형으로 만든 자체 디자인이며 특정 브랜드의 모델·로고를 복제하지 않았습니다.
- 명단·기록은 브라우저 LocalStorage에만 저장됩니다. 다른 컴퓨터로는 JSON 백업으로 옮기세요.
- 캐릭터 이동과 점프는 연출입니다. 공정한 결과는 경기 시작 전에 정해집니다.
- 아주 오래된 PC에서는 '낮음' 품질에서도 끊길 수 있습니다. 이때는 이름표를 끄거나 참가 인원을 줄여 보세요.
