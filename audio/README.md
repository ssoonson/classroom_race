# 배경음악 넣는 곳

이 폴더에 음악 파일을 **`bgm.mp3`** 라는 이름으로 올리면, 어느 컴퓨터에서 사이트를 열어도 그 음악이 나옵니다.

1. GitHub 저장소에서 `audio` 폴더로 들어갑니다.
2. **Add file → Upload files**로 mp3 파일을 올립니다. 파일 이름은 꼭 `bgm.mp3`로 바꿔 주세요.
3. 1~2분 뒤 사이트의 **설정 → 배경음악 → 음악 종류**를 **내 음악 파일**로 고릅니다.

- 이 컴퓨터에서만 쓸 음악이라면 올리지 말고, 사이트의 설정 → 배경음악 → **음악 파일 고르기**를 쓰세요(그 브라우저에만 보관됨).
- 사이트는 누구나 열 수 있으므로, **무료 이용이 허락된 음악**만 올리세요(예: 유튜브 오디오 보관함, 공유마당 자유이용 음원).
- 파일이 너무 크면 처음 재생이 늦어집니다. 5MB 이하를 권장합니다.
